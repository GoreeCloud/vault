# GoreeCloud Vault — Competitive Objectives

GoreeCloud Vault is intended to compete on self-hosting, privacy, strong encryption, offline capability, portability, phishing-resistant credential use, secure sharing, transparent recovery boundaries, and deep GoreeCloud integration without vendor lock-in.

The project should favor reviewed standards and established cryptographic libraries over proprietary constructions, minimize metadata and plaintext exposure, and preserve user control over export, recovery, deletion, and migration.

These are objectives, not current implementation claims.
