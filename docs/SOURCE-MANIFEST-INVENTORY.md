# Vault source-manifest review

Development only. A dependency declaration inventory must be compiled from both pinned Bitwarden source trees before distribution decisions. It does not constitute an SBOM, a license clearance, a vulnerability scan, an independent cryptographic review, or approval to handle real credentials.

Required evidence: exact upstream pinned commits and tree IDs, per-ecosystem manifest paths and blob IDs, source notices, corresponding-source/license obligations, third-party license results, and independent signoff. See `source-lock.json`, `docs/SOURCE-AND-LICENSING.md`, GitHub issue #1, and backlog issue #3.
