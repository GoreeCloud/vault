# GoreeCloud Vault — Objectives

1. Develop a user-controlled open-source password manager with genuinely native Linux and Android applications and a modern browser UI.
2. Encrypt all secrets locally, without plaintext disclosure to storage or a server.
3. Align application design to validated GoreeCloud UI tokens and separate GoreeShield privacy, Wardveil security, GoreeCloud Mesh integration and GoreeCloud Identity boundaries.
4. Preserve portable encrypted data and enable documented, tested backup, import and restoration.
5. Build maintainable modular source, reproducible tests, safe software supply chain and validated platform packages.
6. Reach security-reviewed feature parity where justified with Bitwarden and Proton Pass; never claim unimplemented capabilities.

These are intended goals unless explicit test or release evidence proves completion.
