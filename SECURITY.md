# Security policy — GoreeCloud Vault

This repository currently contains **unreleased, untrusted imported source** and early first-party development components. Do not use it to store passwords, passkeys, recovery codes, API keys or any production secret.

If you discover a vulnerability, use GitHub's private vulnerability reporting or a confidential project-maintainer channel rather than publishing exploit details in public issues. Do not send real passwords or secret keys in bug reports.

No Stable, deployed, independently audited, or zero-knowledge product claims are made by this source baseline. See [Security gates](docs/SECURITY-GATES.md).
