# Security Policy

GoreeCloud Vault is an early development preview **not independently audited and not suitable for protecting important real-world credentials**. No stable supported version is declared.

Never open a public issue with a real password, master password, private encrypted vault, recovery code, API token, access details or exploit evidence. Prefer GitHub's private vulnerability-reporting interface if enabled for this repository; otherwise ask for a safe private contact route without revealing the vulnerability publicly.

Security review priorities and known limitations are tracked in [docs/THREAT-MODEL.md](docs/THREAT-MODEL.md). Source and synthetic tests are not security certification.
