# Security policy

**Current status:** experimental / pre-alpha. **Do not store real credentials or run in production.**

GoreeCloud Vault's security model, limitations and release gates are documented in [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md). Third-party security review has **not** been completed.

For suspected vulnerabilities, do not open a public issue containing exploit details, passwords, live secrets, private personal information or proof-of-concept data taken from real accounts. Use the repository's private vulnerability reporting feature if it is enabled, or contact the repository maintainer through an appropriate private channel.

Only the current pre-alpha branch is under active development. No stable security-support or patch timeline has yet been established. Production deployment and existing password manager replacement are out of scope.
